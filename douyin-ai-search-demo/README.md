# 抖音 · 临时搜索 Tab

一个关于抖音 AI 搜索的交互概念原型：用户从原生搜索页表达当下兴趣；系统将搜索组织成一个临时 Tab，用文字要点串联双列视频内容。

## 体验路径

`点击搜索框 → 选择真实 query → 生成一个临时 Tab → 浏览文字要点与双列视频 → 深挖子话题或打开单列视频 → 返回原位置`

原型预置四种内容组织方式：人物与综艺、知识学习、旅行攻略、日常 Vlog。一次只保留一个临时 Tab；退出后可从普通搜索记录再次搜索。人物、视频、数据和部分内容为概念演示素材。

## 本地运行

```bash
python3 -m http.server 4199 --directory dist
```
